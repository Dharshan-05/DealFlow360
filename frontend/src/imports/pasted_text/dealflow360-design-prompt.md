# DEALFLOW360 — MASTER FIGMA UI/UX DESIGN PROMPT

Design a complete, premium, original web application called **DealFlow360**.

DealFlow360 is an **AI-powered Sales Operations Platform** that connects:

Customer → Product → Quote → AI Discount → Risk → Approval → Negotiation → Fulfillment → Billing → Payment → Deal Health → AI Copilot.

The product should feel like a **next-generation enterprise operating system for sales**, not a traditional CRM and not a generic admin dashboard.

---

# 1. CORE VISUAL IDEA

The primary visual identity must be:

**BLACK + WHITE**

Use black as the dominant background and white as the dominant typography.

The interface should feel:

* Minimal
* Premium
* Elegant
* Professional
* Enterprise-grade
* AI-first
* Modern
* High-end SaaS
* Clean
* Cinematic

Use approximately:

**85–90% Black / White / Gray**

and only approximately:

**10–15% Accent Colors**

Accent colors should be used strategically for:

* AI
* Success
* Warning
* Critical risk
* Active navigation
* Important actions
* Notifications
* Status indicators

Do NOT make the interface colorful everywhere.

Avoid:

* Neon gaming aesthetics
* Cyberpunk
* Excessive gradients
* Excessive glassmorphism
* Rainbow colors
* Cartoon-style UI
* Generic Bootstrap dashboard appearance
* Excessive shadows
* Overly rounded cards

The interface should feel calm, intelligent and expensive.
